# Native host responsibilities and non-claims

This package accepts isolated domain/source/emitted parity only. It changes no Main, native kernel, scene, actor position, audio transport, stock timer or future P13 gameplay.

1. Admit exact caller types/enums, bounded limb values, context inventory and canonical source bindings before lowering. Reject fabricated or foreign callbacks outside the VM and call `p07RejectInput` when typed admission fails. Never dispatch internal helper selectors as player commands
2. Supply current campaign room/apron, PLAN_AGREED, genuine Bunny location/availability/invitation and current pot ownership. Do not undo a P05 escort, teleport Bunny or infer consent. SAVE/RESTORE must capture actor positions, invitations, P07 state and owner map together
3. Prove the entire exact source page was displayed readably through the actual Graph12 path before acknowledgment. Page source/record/index/count/digest are necessary domain receipts, not proof of pixels. Audio end, skip, animation end, LOOK prose or a title cannot grant knowledge. All canonical source records fit the logical48×14 reader; native clipping, pagination and actual readability are still unaccepted
4. Render records with their exact explicit speech-unit slices. Preserve text, punctuation and bindings in the canonical fixture. Do not read the entire scene record for a partial slice. Suppress/retire inappropriate queued laughs/audio on interruption. LAF07 follows only comic.02 once; protected sincerity never awards it
5. Prepare every possible failure before host commit: physical projection, exact output rendering and queue capacity, save bytes, owner-map destination and rollback. Freeze input/save/restore/callback dispatch until final domain commit. The prototype MemoryTransactionHost plus explicit candidate/abort tests verify a logical protocol, not real native atomicity
6. Keep the same pot on the stove/kitchen waiting point with its lid until real P13 authorizes the ownership transaction. Failed cooking inputs consume nothing; supplies refill until completion. Recipe reading gates eight tasting bowls. Jug-mark and herb-label reading are optional. Base and stock order is flexible, vegetables require base, cooking is immediate, heat goes off before herbs, and the lid grants readiness once. No timer, burn, spoilage, toxicity, extra pot or eight full-supper multiplication exists
7. Real P13 must independently establish campaign introduction, eligibility, helper consent, route, seating/buffet requirements, current ownership and current-session authorization before this handoff. P07 merely validates declarative identities and releases its single pot atomically. A copied delivery serial can be reused after restore; it is not a capability. No SERVED event or SERVE confirmation is implemented
8. Retire all callbacks OUTSIDE the restored VM before allowing any saved dispatcher to resume. SCI locals, class/instance properties, heap strings, session words, queued output and nonce counters are restored state. `p07AfterRestore` clears in-VM readiness/input/output; `p07BindSession` rejects the immediately saved session but cannot prove freshness across all overwritten timelines. The host owns fresh external leases and build/save identity checks
9. Compile the eventual whole game coherently with every accepted module and one selector/class vocabulary. The baseline proof reserves species9 for P06 without implementing it. P07 selectors occupy its1800–1999 reservation; P06 has1600–1799. Do not splice standalone script/heap/SCO files, and do not change the accepted Main to make a domain proof look playable

Remaining gates: independent domain review, native host/scene integration, actual full-page display receipts and exact audio slices, save/load/interruption behavior in stock ScummVM, native transactional failure behavior, and real P13 gameplay. None is silently promoted to PASS by the isolated proof.

For whole-VM restore, validate the restored payload AND its campaign context before using or publishing any projection. A host can reconstruct the bounded219-word native envelope from the suspended restored state and stream it through `p07LoadCommit(1)` after context admission, provided the external save/build identity has already been checked. A failed check keeps dispatch suspended; it does not repair the restored words. Only after successful validation should the host bind its freshly allocated external lease/session and resume. Read-only projection accessors assume that admission has succeeded; they are not a substitute for validating an arbitrary whole-VM save.
