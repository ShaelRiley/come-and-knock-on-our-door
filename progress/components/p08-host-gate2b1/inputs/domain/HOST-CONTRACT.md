# Future P08 R2 host integration contract

This domain is isolated. Do not splice its standalone compiled script/heap or
vocabulary into the current game. Import the editable source into a fresh
coherent whole-game compiler universe, preserve every accepted selector/resource
ID, and remeasure Main and all typed resources. Allocate native objects, menus,
text/audio modules and actor aliases separately. Script 989 carries the logic;
Main should receive only small dispatch hooks. No host allocation is implied by
this package.

1. Build the 13 preparation facts from actual campaign histories. VC01/VC02 losses
   still resolve their gates. Never invent wins, P14, consent, source knowledge,
   later puzzle rewards or E03 from a menu. Keep earlier branch saves unchanged
2. Retain one authoritative physical owner per object. A first carrier placement
   includes its service; PA, full screen, and credit slate move once. Unpack
   returns exactly P03's original cloth once to the kitchen linen hook. Preserve
   the three tiles, pencil/master, wedge/peg, handcart, Rita's panel, and sole
   lidded eight-tasting-bowl pot in the kitchen until actual P13
3. For every action, admit the whole bounded domain candidate output and prepare
   all host storage before publication. Serialize input and forbid callbacks in
   the critical section. Retire the old projection and publish the new physical
   owner together. Record the original transfer serial for idempotent recovery;
   ACK only that transfer. Definitive unchanged failure aborts the candidate;
   uncertain partial publication locks the domain until whole-campaign recovery
4. Present only the exact mapped canonical records/units. Successful actual page
   display may authorize a source ACK. Look, muted/skipped audio, captions,
   journal, hint, and menu visibility alone authorize none. Domain IDs do not
   prove a native reader showed a page; the host owns that evidence
5. Real Talk to real Frankie opens readiness. Both P08.DIALOGUE.002 and
   P08.SYSTEM.004 must have completed actual display before the exact checklist
   ACK. An explicit user Yes can then confirm and emit the save request. No
   layout query, default menu selection, audio completion or cancellation is Yes
6. Commit the confirmed AUTOSAVE pending request, then save the whole campaign
   before transition, including branch states and authoritative owner map. The
   actual native save backend must verify successful I/O before a true ACK.
   Failure leaves confirmation pending; retry emits another request, and cancel
   prevents late completion. Restoring the pre-transition save resumes/retries
   that pending request and does not inherit later evening completion
7. Only the accepted successful-save ACK exposes EVENING_STARTED, the exact
   saved line and E03 phase event. The host then performs the real transition:
   Bunny kitchen; Frankie living room; Stringer/Rita conservatory; Milo/Vivian
   courtyard; Felix side passage. Essential access stays available. P09 begins
   only after this gate; P10 remains independent; no later completion is granted
8. Retire reader/render/save leases on restore, room/session replacement and
   layout invalidation. The callback envelope includes both session and revision.
   An externally stale callback cannot be made current by relabeling its token
9. After E03, reversible layout remains allowed except for caller-protected
   occupied furniture. PA facing is independent, the hatch is an object
   interface rather than a travel exit, and the apron allows no manipulation

The new test harness stages numeric domain ACKs and owner-map updates separately
without spoofing that identity. Native host integration, keyboard/mouse/controller
routes, exact rendered receipts, real SaveGame failure/retry and ordinary native
restore, art and listening acceptance are not claimed here.

metadata in every raw save. When importing a valid reference JSON snapshot,

serial. Enumerate pending transfers through `p08PendingKey`; ACKed keys remain
in the saved full order, and future first transfers append after them. R1 raw
