# Verification scope by revision

COLD-REBUILD.json, STATIC-REFERENCES.json and CLI-REPORT-SCOPE.json remain the
unchanged r16 reports, bound to the r16 source manifest and receipt. They are
historical evidence and do not report execution of the adapted r17 public tools.
ASSET-REGENERATION.json applies to the unchanged asset inputs and authoring subset.

R17-STATUS.json summarizes previously completed checks of the exact r17 program.
The r17 public builder, current-pin static wrapper and portable trace verifier
were reviewed for packaging but were not compiled or executed in this source
update. No whole-suite pass is claimed. The public output pins are reference
identities from the previously reviewed candidate, not a fresh public cold-build
receipt. Native observations are bounded and do not establish complete campaign,
ending, universal save compatibility, or diagnostic-mode behavior acceptance.
