Six source/emitted cases pass in two completed suite chunks on the same frozen source, compiler and test bytes. They cover the real overlay and slate dispatch, all four source documents, exact Graph12 receipts, partial reads and ordinary restore, all eight domain-session words and actor-room identities, thirty stale-identity mutations per backend, three Graph return profiles, failed flush, direct flush, whole-queue reservation, uncertain publication, cancellation and corrupt saved descriptors. The source operation first obtains the literal read-only domain output. It reserves canonical pages/units, the complete existing root queue prefix, the new slot, descriptor storage and a nonwrapping two-word presentation serial. Only then does it publish the committed output, queue and descriptor under the existing critical barrier. An unchanged reservation failure aborts the candidate. An uncertain publication locks the whole campaign. ## Completed display boundary

Main captures the exact eligible source identity at render entry and clears the reader's old paint generation. At Main's original final screen-flush point, script989 now performs the exact Graph12 call itself. Only after that kernel returns does it compare the current identity and painted generation and stamp a one-use completion token. Consequently, calling the completion method directly also performs Graph12; it cannot claim that an unflushed DrawCel reached the screen. The legacy path retains Main's original flush when no P08 gateway exists.

Graph12 preserves its incoming accumulator in the pinned engine. The host ignores that numeric return. The deterministic kernel profile now preserves the incoming VM accumulator too; a simulated failed update aborts control flow. The source receipt requires document, page, generation, queue slot/kind/index, group, full-record mode, revision, all eight session words, actual room/apron and actual rooms for all eight canonical cast identities to remain equal. It validates the canonical row/resource/entry/parts/header and silent speaker/audio tuple. Opening, sdPresented, audio completion/skip, menus and stale or obscured frames are insufficient.

Only actual complete-record page masks can call the domain ACK. Source990 has two pages; mask1 is a partial saved reader, not an observation. Repeated painted pages cannot fill another bit. After completion, repeated redraws cannot produce another observation. Existing unit-only window mode is expressly excluded from source authority, even when its numeric range covers a whole document.

## Restore and cancellation

Before old publishers can normalize anything, raw restore checks the domain/peer source serials and descriptor, actual queue/page/window, captured context and zero frame storage. The ordinary whole-campaign path then retires native events/audio and the transient frame. After admitted session rebinding, it updates only the validated descriptor's lifetime/session; retained page bits belong to that snapshot. No saved frame or later timeline's observation is imported. Closing or replacing the reader retires its descriptor; it never marks missing pages seen. All old inventory and actor-route guards remain active.
