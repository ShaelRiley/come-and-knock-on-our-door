## Finite and host boundary

The image has61 saved words, including25 high/low serial pairs. Serial arithmetic
uses base32768 and stops at1,073,741,823. The unchanged Python reference remains
unbounded; valid values beyond the SCI envelope are rejected by the transport.
Introduction reserves two serial commits atomically. Repeated already-completed
operations can still report their idempotent result at the maximum.

Callbacks use a transient signed-word host context epoch1–32767. A context must
strictly increase within the session. Exhaustion/reuse invalidates the current
lease and cannot mutate saved state. AfterRestore drains the current buffers,
held projection and leases, and resets this transient epoch to0. A real restoring
host must discard all old callback objects before installing a new context;
this domain gate is not a native callback-lifetime or save-kernel proof.

Context validation rejects duplicate external ownership and unearned host flags.
As in the accepted reference, action entry requires a valid established context
but does not automatically consume campaign transfers. The caller must check
p10ValidateContext and apply inventory-transfer events. This is an explicit
host obligation, not a claim that arbitrary host projections are self-correcting.

State load is the ordinary isolated property image plus p10AfterRestore; it is
not a native SCI SaveGame/RestoreGame file. Source and emitted tests compare
returns, saved state, event payloads, captions, queries, and (paired finite
routes) every property and local array. Native rendering, audio, input, host
composition and playable acceptance remain unproven.
