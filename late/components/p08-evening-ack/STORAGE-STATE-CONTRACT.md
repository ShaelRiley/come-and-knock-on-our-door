# Bounded automatic checkpoint state

h8S is selector 2990. No other selector was added. Private h8IO has 29 words: state; unsigned32 attempt generation; request pair; current revision pair; readiness group; session lease; route epoch; checked physical slot; success bit; failure reason; eight session words; eight actual actor-room words. h8IP has the same staged descriptor plus one prepared flag. Fixed GetSaveFiles storage is 361 words for names and 20 for register IDs; the suffix pattern has four words.

States: 0 has no pending attempt; 1 queues exactly one attempt; 2 is synchronous in-flight I/O; 3 waits for explicit retry/cancel; 4 is a current-timeline host I/O receipt. Reasons: 1 invalid enumeration result; 2 ambiguous first slot; 3 all 99 slots occupied; 4 SaveGame did not return true; 5 ordinary restore retired prior authority; 6 context validation failed; 7 existing audio preparation refused. A failure never schedules itself again. Whole-campaign validation failure locks the host for recovery.

Attempt identity is staged before the domain confirmation/retry commit and copied only after validated publication. The stage must be queued, have the exact next serial and zero slot/result/reason. Actual final Yes is the only route to an initial attempt. An explicitly selected Begin in failed/restored phase3 calls literal p08RetryAutosave with the captured callback, reserves its complete empty output publication, updates current revision/group and stages one new attempt. Direct op6 is rejected. Not Yet, ordinary layout, source reading and departure retain literal cancellation authority.

The existing ordinary advance gateway invokes h8S(0). It refuses current input, dirty/uncomposed world, opening/menu/pause, reader/queue, actor movement or wrong room. After current whole-campaign, ownership, queue and actual preparation/layout validation, it retires prior stage/foley/speech and uses existing musicBeforeChooser/musicAfterChooser. h8Critical remains zero in the native snapshot. Main receives only a narrow in-flight readSave guard, whose live predicate excludes rejected/restoring host lifetimes; ordinary actions and saves are blocked during state2.

The exact slot call sequence and source pin are in STORAGE-CONTRACT.md. Only the actual synchronous SaveGame return equal to1 and unchanged request/revision/session/epoch/generation can publish state4. The code does not infer success from enumeration, existence, a chooser, a manual save or a restored marker. h8S(6) requires a valid, enabled, non-restoring host with no failure; it is a pure current receipt query; it does not call the save kernel or repair state. The literal p08AcknowledgeAutosave and all E03 effects remain disabled.

The written file contains phase3/state2/result0. Raw admission checks all peers before prior inventory publishers. Restore clears staged publication and replaces any queued, in-flight, failed or success state with failed/restored state3, increments the saved attempt generation and rebinds the new session. No old continuation may clean up or acknowledge the restored timeline. A new explicit retry must perform a fresh full preflight and genuine SaveGame call.

Twenty completed cases cover both source/emitted backends: five storage cases, five confirmation boundary cases, one ordinary source/layout/room crossing, all six source-reader cases and three selected intro regressions. They include 25 simulated manual files, capped20 enumeration, allocation26, no repeated writes, in-flight whole-snapshot restore and explicit retry to27; sparse/full/ambiguous/unsupported slots; false completion and reentry; stale returns; and corrupt/staged receipt recovery. Prior domain words, owner receipts and actor rooms remain exact and evening stays false. The original failed recovery case and the precise correction are retained in RECOVERY-GUARD-CORRECTION.md. The deterministic backend models exact-tag kernel behavior with in-memory files; it establishes no native filesystem success, pixel rendering or listening.
