# Public source edition provenance and rights

The accepted component archive hashes are in `manifests/COMPONENTS.json`.
Each input mapping records its relative source location, SHA256, byte length
and executable mode. Publication changes are listed individually. A fresh
source-only reconstruction here means that this edition contains all declared
editable inputs and necessary ancestor fixtures and reproduces the declared
outputs; it does not mean that every frozen ancestor output was removed.

## Explicit dependency adaptations

Administrative package archives, recovery message packets, private identities
and review coordination are omitted. Required technical target/hash/size
inventories remain, rebound to this edition. The P12 reference still checks
its unchanged literal prefix plus explicitly reconstructed tail. Current
canonical authority, models, SCI methods, codecs and semantic test assertions
are retained. The top-level exact inventory guards all included public bytes.

P09 geometry's required foundation-review input is replaced with a short
public source-acceptance and limitations summary. P12–P14 reference guards
retain technical dependencies without private origin paths or raw message
packets. These are new public-edition input identities, not the original
package seals. Packaging and metadata corrections do not silently extend
independent gameplay acceptance.

The P11 scene's unchanged packaging test needs a compiler-source ZIP. Its
historical883-member ZIP is replaced with one deterministic199-member archive:
198 approved corresponding-source files plus the exact source manifest.
Old/new ZIP hashes are recorded in the component change list. Its members
are the same approved source bytes already available as editable files in the
baseline. The test still compares every archive member and digest and checks
license presence; no assertion is removed. No broader vendor archive is used.

P10–P13 generated manifests describe their protected public input inventory;
that metadata and its extension-contract hash consequently differ from the
original working archive. P12 additionally omits a private Audience artifact
identifier. All other generated fields and all declared compiled, text, audio,
font and scene payloads retain their independently accepted output identities.
Exact comparisons are in `VALIDATION.json`.

The renderer and ACK are separate accepted components. The renderer's retained
final packet contains build-provenance paths from its earlier frozen directory;
only that known component-root prefix is normalized for cold comparison. The
P09/renderer/ACK typed-resource inventory row order is normalized while every
field, typed identity and resource hash remains checked.

The historical ACK predecessor-comparison script requires a separate old
storage worktree and is not shipped as a self-contained public command.
Instead, every accepted new source/compiled payload is pinned; the unchanged
emitted-method audit and current source/emitted test runners are included and
remain executable. This does not claim a new predecessor audit or new native
filesystem acceptance.

The deterministic P11 compiler ZIP can be independently rebuilt with
`python3 late/tools/rebuild_compiler_archive.py --out /absolute/new/compiler.zip`.
Its archive identity is checked against the component map.

## Historical report scope and current commands

Retained historical component reports preserve the evidence paths and commands
from their original review context. Private review packets and administrative
archives omitted from this public edition are not bundled merely because an
unchanged historical report names them. For example, P14 domain's
`reference/CORRECTION-R2.md` refers to `prior-revisions/v1` and `review-v1`, its
`inputs/REFERENCE-INDEPENDENT-ACCEPT.md` names an excluded source ZIP, and P12
domain's `COMPILER-CLOSURE-CORRECTION.md` refers to an omitted
`provenance/compiler-closure-correction` directory. These are historical evidence
references, not current public reconstruction steps. Use `late/README.md` and
`late/reproduce.py` from the repository root for the supported public commands;
`late/manifests/COMPONENTS.json` defines their exact included input closure.
