queues were not inspected natively. Portable tests supply exact state assertions;
UI observations establish visible behavior. All native saves discussed here
were ordinary in-engine saves/restores of the same build, with one preserved
pre-repair checkpoint additionally restored. Arbitrary version migration is
not supported by this summary or by equal static layouts alone.

The original card has generic inventory/status labels. Some rejected actions,
including premature Rita discussion and occupied-rack moves, lack explanatory
feedback. Bunny's upper-body hotspot overlaps the kitchen hatch; the lower-body
hotspot selected Bunny successfully.

Interrupted/unseen-reader granting, every mute/skip/reopen permutation, every
optional source and all puzzle branches were not exhausted. Artwork, animation,
audio polish, accessibility, controller hardware and other platforms were not
accepted by these checks. No P11+, final ending or whole-game acceptance is
claimed. Raw reports, private save files and audiovisual evidence are omitted.
