# Editable audience and material audio

Original source previews/recordings, historical decoded contacts, licenses and provenance are retained under assets/. Runtime PCM lives in ../../source/assets/audio. build_assets.py reconstructs the expanded takes with Python 3, NumPy, SciPy and FFmpeg; its only public-package changes are local input paths and a 33-source credit lookup replacing a larger narrative catalog. Run in a copied authoring directory to preserve these frozen inputs.

The bank contains 24 distinct source-labeled laughter performances, not 24 subjectively auditioned takes. Technical measurements do not establish naturalness, wordless content or appropriate tier. Subjective listening remains unperformed. Every source retains its own license and adaptation description in CREDITS.md.
