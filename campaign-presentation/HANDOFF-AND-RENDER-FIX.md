## Right-click room exits

After Bunny accepted the courtyard invitation, a right-click room exit moved
Jackie while cancelling the pending accompaniment. The world shortcut called
`uiCancelSentence` before dispatching its default verb. That routine cancelled
both the P12 companion request and the P13 delivery request.

The shortcut now supplies its actual hit object's identity. The sentence reset
preserves the pending request only for an ordinary room exit whose default verb
is WALK, outside panels, the audience apron, opening and pause states. A closed
side gate is excluded. Calls without an argument retain the original
cancellation behavior. Readers still retire, and the original travel, ownership,
crossing, destination, delivery and arrival checks remain unchanged.

## Repeated descendant scans during drawing

With the P12 successor lease active, native walking and redraws became very
slow. Several getters repeated the complete predecessor and actor-history scans
within the same presentation frame; P13 and P14 had the same descendant pattern.

The existing P11 read-only render scope now bounds reuse of a successful
`h12SuccessorValid`, `h13Valid` or `h14Valid` result. Each controller's flag is
reset at the beginning of the scope. Reuse requires the unchanged
`h11ReadMemo`/`h11ReadGuard` admission and the correct controller identity. The
original strict predicate body is preserved byte for byte.

At scope end, reuse is disabled and every reused predicate runs strictly again.
All close checks execute even if an earlier check fails. The unchanged Main
render path publishes the frame and invokes acknowledgements only after that
combined end check succeeds. Input, setup, travel, save/restore, acknowledgements
and ending progression retain their strict checks outside the drawing window.
This does not grant any puzzle, contest, source-read or credit progress.

Six new selectors occupy previously unused IDs; every existing selector ID is
preserved. One local word is appended to each descendant script, preserving the
old local offsets. The build now writes the canonical game title to `game.ini`
for both candidate and release builds.
