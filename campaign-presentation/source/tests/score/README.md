# Focused emitted score checks

Run `python tests/score/run.py` from the source root after the coherent SCI build. An optional list chooses individual cases. Each case starts a fresh process and writes its own status, compiled receipt hash, elapsed time, exit code and peak RSS under results.

The bytecode interpreter loads actual freshly compiled scripts and current ABI mappings. Kernel audio and Save/Restore behavior are explicit bounded models, not native captures. Only held/running cases create compact typed in-memory snapshots; no retained Python VM graph or native save is produced. The finite case configures an isolated music owner and does not fabricate campaign facts or domain admission. Tests are kept separate from native campaign acceptance.
